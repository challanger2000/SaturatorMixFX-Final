# 125A SMX-3 – User Manual

## 1. Overview

SMX-3 is a free saturation processor by **125A**. The package contains two plug-in variants:

- **SMX-3 Mix FX** for the Mix FX slot in Studio One / Fender Studio.
- **SMX-3 Channel** as a conventional VST3 insert for individual channels and buses.

Both variants use the same fundamental saturation and tone-shaping engine.

## 2. Installation

Copy both `.vst3` bundles to:

`C:\Program Files\Common Files\VST3`

Restart Studio One / Fender Studio afterwards or rescan plug-ins if required.

## 3. Which version should I use?

### SMX-3 Channel

This version is loaded like a conventional VST3 insert effect. It can be used on instruments, vocals, drums, buses or the master channel.

### SMX-3 Mix FX

This version is specifically intended for the Mix FX slot in Studio One / Fender Studio. It is not used there like a conventional insert effect.

## 4. Controls

### Bypass / On-Off

Enables or bypasses processing. In bypass, the signal is not processed by the saturation stage.

### Drive

Controls how strongly the signal is driven into saturation. Lower settings provide subtler density and coloration, while higher settings create more pronounced harmonic saturation.

### Character

Three tonal characters are available:

- **Triode** – softer, warmer and more rounded.
- **Pentode** – more direct, aggressive and harmonically rich.
- **Iron** – denser, weightier and transformer-like in character.

### Mix

Controls the balance between the dry and processed signals. 100% is fully processed. Lower values allow parallel saturation.

### Output

Controls the output level after processing. Use it to compensate for level differences between the processed and unprocessed signal.

## 5. Automation

Bypass, Drive, Character, Mix and Output can be automated in the DAW.

## 6. Practical tips

For subtle bus or master saturation, start with a low to medium Drive setting and reduce Mix if necessary.

For stronger coloration or more aggressive sounds, increase Drive and select the Character mode that best fits the source.

When comparing processed and unprocessed sound, adjust Output so both are approximately equally loud. This makes the actual tonal effect easier to judge.

## 7. System requirements

- Windows x64
- VST3-compatible host for SMX-3 Channel
- Studio One / Fender Studio for SMX-3 Mix FX
